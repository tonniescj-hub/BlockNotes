# 方块书房：读书笔记更新开发计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Windows 本地书房中完成 Word／PDF 导入、阅读摘录、心得写作和 Word 导出闭环。

**Architecture:** 保留 Electron、React、Three.js、Tiptap 和 SQLite；阅读资料、批注与现有笔记分开保存，以稳定 ID 关联。PDF 使用独立文档阅读内核，Word 转换为可重排的阅读内容，写作继续复用现有编辑器。导入与附件处理在后台执行，新增文件纳入备份恢复。

**Tech Stack:** 现有技术栈不变；PDF 阅读、DOCX 解析与生成依赖在第一阶段通过官方资料、许可证和中文样本文档验证后锁定，不自行实现文件格式解析器。

**Spec:** 本文整合本会话截至 2026-11-13 的产品要求；基础规范为根目录 `AGENTS.md` 与 `BlockNotes_项目开发计划书.md`。这是待用户审阅的开发范围，不代表功能已实现或兼容性已验证。

## 一、产品范围

定位：一间能阅读学习资料、记录摘录和撰写心得的本地 3D 书房。

核心流程：导入 Word／PDF → 在讲台阅读 → 划线并写想法 → 将摘录加入自己的笔记 → 导出 Word 并在本机 WPS 中打开。

保留独立新建笔记，不强制先导入资料。新功能沿用书架、讲台、书与笔、指南针入口，不新增首页仪表盘，不强行填满九格物品栏。

### 第一版必须完成

| 功能 | 明确范围 |
| --- | --- |
| 资料导入 | 本地 `.docx` 与 `.pdf`；原件复制进应用管理目录，原路径文件移走后仍能使用；同内容重复导入提示打开已有资料或另存 |
| Word 阅读 | 转换为可重排内容，优先保留标题、段落、列表、强调、链接、内嵌图片、普通表格；复杂排版提示限制，原件始终保留 |
| PDF 阅读 | 保留原始页面；缩放、翻页、页码跳转、已有文档目录；文字型 PDF 支持选择与检索 |
| 扫描 PDF | 可以阅读、记住页码和写页级心得；无文字层时明确提示不能选择文字，不加入 OCR |
| 继续阅读 | 记住每份资料的位置；PDF 按页及页内位置，Word 按内容锚点；目录在原文有相应结构时提供，不自动猜章节 |
| 摘录与想法 | 选中文字后手动划线或写想法，首版一种高亮颜色；批注可编辑、删除；集中查看该资料的摘录 |
| 出处定位 | 摘录可返回原文；PDF 保存页与定位区域，Word 保存块标识、文本区间和引用上下文；定位失败显示摘录并提示，不能跳到错误位置 |
| 自己的笔记 | 沿用现有编辑器；从资料摘录列表将选中摘录插入指定笔记，保留来源文本和关联 ID；已有笔记无需转换 |
| 基本整理 | 沿用书架与标签，新增资料／笔记筛选、最近阅读；沿用归档与回收语义 |
| 搜索 | 搜索资料中可提取的文字、摘录和笔记；显示命中片段和类型，支持书架／标签筛选；扫描 PDF 不宣称全文可搜 |
| Word 导出 | 导出当前笔记，或将一份资料的摘录与想法汇总为 `.docx`；写入来源名称、章节或 PDF 页码，保留可携带的文字出处 |
| WPS 打开 | 成功导出后提供打开入口；能明确识别 WPS 时调用，否则交给系统默认应用并如实命名；打开失败不影响已导出的文件 |

Word 导入默认是阅读资料，需要修改原文时调用外部程序打开原件副本。个人心得在方块书房中编辑。首版不提供 Word 原文双向编辑同步。

### 后续小版本：保留但不挤入第一版

1. 收藏与手动书签，补充多个常用阅读位置。
2. 笔记历史快照：预览并恢复为副本，不覆盖现稿。
3. 备份列表、校验结果与恢复入口；第一版已必须支持新增资料的完整备份。
4. 批量移动、归档和简单排序；保留现有事务与版本检查。
5. Markdown 导入，以及笔记之间手动插入链接；摘录返回来源不依赖此项。

暂不加入脑图、知识图谱、AI、复习卡片、任务积分、社交、云同步、装饰系统和复杂统计。暂不支持旧 `.doc`、宏文档、OCR、PDF 编辑、复杂 Word 修订批注的转换及 WPS 实时同步。旧 `.doc` 可先在 WPS 中另存为 `.docx`。

## 二、交互方案

- 书架：统一列出资料和笔记，通过小图标和筛选区分；导入入口放在书架中。
- 讲台：阅读正文为主体；复用可收起侧栏，提供选书、目录和摘录切换；小窗口避免三栏挤压。
- Word 与自写笔记沿用书页感；PDF 保留完整页形，不强制塞进现有笔记分页器。
- 选择文字不会立即生成摘录；工具条明确提供划线、写想法。复制文本仍使用系统快捷键。
- 摘录列表提供加入笔记、查看原文；第一版不做拖拽卡片与自由画布。
- 书与笔：继续编辑自己的笔记；导出按钮置于笔记次级操作中。
- 指南针：搜索结果显示资料／摘录／笔记与上下文；打开后定位命中位置。
- 导入显示进度、可取消、逐项错误；失败不可留下看似成功但无法打开的条目。
- 阅读、缩放和翻页只更新阅读状态；批注独立保存，不修改原文及现有笔记 revision。

## 三、全局约束

- Windows、本地优先、离线运行；首次既有资源准备规则不变。文档转换不得依赖云服务。
- 固定 3D 书房、受限鼠标视差、九格物品栏；保持原版 Java 1.21 资源管理边界。
- 设置仅从 Esc 菜单进入；弹窗暂停视差，中文输入优先。
- 数据变更需事务、版本检查、明确失败提示；迁移前保留完整 SQLite 快照。
- 原始资料不可因归档、书架移动、删除关联笔记而被连带删除；来源进入回收区后已插入笔记的摘录文本仍保留。
- 附件以受控 ID 与相对路径管理；不信任文档内脚本、外部资源地址和压缩包路径，不自动执行宏或联网加载图片。
- 数据库与文件不能假装处于同一个事务：采用暂存、校验、提交和异常清理协议，启动时处理残留暂存；验证成功前不展示可用资料。
- 新备份必须覆盖原文件、提取内容、批注、阅读状态和笔记；后台流式处理，按 ID 和内容快照合并；旧 JSON 备份继续可恢复。
- 不覆盖用户改动，不公开发布本地原版资源。未经实测不承诺复杂 Word 排版、所有 PDF 或 WPS 版本完全兼容。

- [ ] 建立虚构中文测试资料：基础／复杂 DOCX、文字 PDF、扫描 PDF、损坏文件、重复文件和较大文件。
- [ ] 验证并锁定文档内核，记录来源、版本、许可证、转换保留项与限制。
- [ ] 增加资料、批注、阅读状态存储及稳定 ID；不改写现有笔记内容模型。
- [ ] 实现后台导入、取消、原件管理和重复检测，测试故障中断后的恢复。

- [ ] 将资料接入选书与讲台；实现 PDF 缩放、页码和目录，Word 内容阅读与目录。
- [ ] 实现阅读位置保存及恢复，窗口缩放后验证 Word 定位和 PDF 高亮位置。
- [ ] 实现文字高亮、想法、摘录列表与返回原文；扫描件提供页级心得。
- [ ] 验证 Esc、中文输入、缩放及只读行为；阅读操作不能修改笔记 revision。

交付：实际阅读两种资料，摘录、关闭、重启后可继续阅读并找回批注。

### 阶段 3：写作、检索与 WPS 互通

涉及：`src/BookEditor.tsx`、`src/App.tsx`、`server/storage.cjs`、Electron 文件操作；新增 DOCX 导出模块。

- [ ] 摘录加入已有／新建笔记，携带引用文字与出处；来源不可用时笔记仍可读。

## 五、重点风险与所属验收

| 风险 | 必须验证的结果 | 阶段 |
| --- | --- | --- |

## 六、执行原则

先交付阅读与写作闭环，再补便利功能。每阶段保持旧版能力可运行，按任务补有意义的自动化测试；涉及排版和 WPS 的结果必须人工或 GUI 实测，不能用生成成功替代兼容验收。执行时先复核实际代码与工作区，再为当前阶段细化接口和测试，不预先实现后续功能。
