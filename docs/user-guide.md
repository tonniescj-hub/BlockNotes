# 使用教程

首次资源准备和下载步骤见 [开始使用](getting-started.md)。以下截图为实际 Windows 应用与虚构学习笔记。

## 1. 写下一篇笔记

点击下方第一格“书与笔”，或按 Ctrl+N，新建一篇空白笔记。点击书页直接输入，支持中文。编辑器自动保存，也可 Ctrl+S 立即保存；只有保存成功才显示成功状态。

打开“书名与标签…”修改标题、添加标签、选择所在书架。“格式…”提供粗体、斜体、小标题、列表、引用和代码块。

![书与笔编辑](screenshots/editor.png)
![标题、标签与书架](screenshots/metadata.png)

点击页角翻页。书与笔末页的下一页会新增空白页，并在保存后保留；很长的正文会自动排版，不截断正文。返回书房前应用等待可靠保存；若保存失败，应保留窗口并处理错误，不能把失败提示当作已经保存。

## 2. 在讲台阅读

点击场景讲台或第五格物品，进入独立 3D 阅读近景。左侧选择笔记，可按书架分类或搜索标题、正文、标签；右侧只读翻页。阅读不会修改正文、创建空白页或提升笔记版本。

收起左侧列表可以专注阅读；点击“继续编辑”返回书与笔。Esc 或“返回书房”回到首页。

![讲台工作台](screenshots/lectern.png)

## 3. 管理书架

点击书架或第四格物品查看分类和笔记。点击书的图标打开它，悬停可查看书名与内容摘要。通过“管理书架”重命名或新增自定义分类。

自定义分类可以删除；非空时必须选其他书架接收其笔记，正文、归档和回收状态都保留。两个绑定场景的基础书架只允许重命名。

![书架管理](screenshots/shelves.png)

## 4. 搜索与命名

点击指南针或 Ctrl+K，搜索标题、正文及标签。支持中文短词；多个词一起输入时按全部词匹配。归档笔记可以搜索，回收区笔记不在普通搜索结果中。

命名牌按书名筛选；打开笔记后进入“书名与标签…”修改。搜索命中后可直接阅读。

![全文搜索](screenshots/search.png)

## 5. 归档与删除

在编辑器的“书名与标签…”中点击“收进归档箱”，笔记从日常书架收起，仍可检索。在箱子的归档区选择“放回书架”恢复。

删除入口也在同一侧栏：**“移入回收区…”**。确认后正文保留，箱子切换到“回收区”可恢复。当前版本没有永久删除按钮。

![归档箱](screenshots/archive.png)

## 6. 备份与恢复

在书房按 Esc → 选项，使用“导出备份”生成包含正文、标签、分类和状态的 JSON。“选择备份并合并”恢复到当前库，不清空已有笔记。

同来源、同内容的重复恢复跳过；同 ID 不同内容保留冲突副本；用户修改过的恢复副本继续保留。大备份在后台流式处理；等待完成提示再关闭。旧 schemaVersion 1 备份保持兼容。

备份保存后应另存到可靠位置。`examples/study-notes.json` 只是文案源，不能作为备份文件恢复。

## 7. 暂停、选项与唱片

书房中 Esc 打开暂停菜单，菜单暂停视角和音乐。容器中 Esc 先关闭当前界面；选项与指引中 Esc 返回暂停菜单。退出使用“保存并退出”。

![暂停菜单](screenshots/pause.png)

唱片机位于窗户前、讲台右后方，也可通过第七格打开。选择 19 张唱片中的一张播放，支持上一首、下一首、暂停、进度与独立音量。关闭唱片窗口继续播放；重启只记忆选曲和音量，不自动播放。

![唱片机](screenshots/jukebox.png)

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl+N | 新建笔记 |
| Ctrl+S | 立即保存 |
| Ctrl+K | 全文搜索 |
| 1–7 | 书房中的七个功能入口 |
| Esc | 关闭当前界面 / 暂停菜单 / 返回上一级 |

输入法组合输入期间不触发书房快捷键。第八、九格预留，没有额外游戏机制。


## 阅读 Word / PDF 学习资料

在书架点击「导入 Word / PDF」。`.docx` 按内容重新排版，保留原件；`.pdf` 按原页面显示。旧 `.doc` 请先在 WPS 另存为 `.docx`。原件随资料存入本机数据库，原路径文件移动后仍可阅读。

在讲台选中文字后，在「摘录」侧栏点击「划线保存」或输入想法再保存；扫描 PDF 可以点击「写本页想法」，不支持 OCR。点击摘录可返回原文；「加入笔记」可创建读书笔记或追加到已有笔记。Esc 和窗口关闭会等待已启动操作及未完成想法保存。

「资料信息」可以修改名称、标签、书架、归档或移入回收区。查找可检索资料可提取的文字、摘录与想法；文字型 PDF 和 Word 支持文字检索，扫描件不保证可搜。

在笔记底部选择「导出 Word」；讲台也可「导出摘录 Word」。导出成功后点击「用 WPS / 默认程序打开」：能从本机注册表定位 WPS 时用 WPS 打开 DOCX，否则用系统默认程序。不会自动将 WPS 修改同步回原资料，再次导入是独立资料或副本。

备份继续在 Esc → 选项中。含阅读资料的备份为 schemaVersion 2，包含原件、批注及阅读位置；本版继续接受旧版 JSON 备份。不要用旧版程序恢复新版资料备份。复杂 Word 版式、页眉页脚和修订批注请通过「另存原件」在 WPS 查看。单份原文件上限 512 MB，Word 解压内容上限 256 MB、单项 64 MB，转换 HTML 和 PDF 提取文字分别上限 32 MB；超过时提示拆分，不静默截断。


## 0.2.1：阅读与笔记往返

在讲台「摘录」页勾选多条摘录（一次最多 500 条），选择新建或已有笔记，再点击「加入笔记（数量）」。按原文顺序整理，引用、出处和心得一起写入；同一笔记已经加入的来源跳过，不覆盖你修改过的笔记。若后来修改批注，需要自行更新笔记中的对应内容。

从讲台进入笔记后，「返回阅读」回到刚才的资料位置；讲台中的「继续笔记」返回这篇笔记。笔记页码在本次应用会话中保留，重启后资料阅读位置仍保留。查看特定摘录出处仍在「书名与标签…」中。

Word 导出使用一个固定 A4 中文版式，不需要选择模板。标题、正文、引用、列表和显式分页可导出；图片、表格属于原资料阅读能力，笔记编辑器本版仍不提供图片/表格编辑。复杂原件继续通过「另存原件」在 WPS 打开。
